# 三件事 · 每日核心任务

> 聚焦每日三件核心事项，深色主题单文件 HTML 网页应用。

[![GitHub Pages](https://img.shields.io/badge/🌐-在线预览-blue?style=flat)](https://guiii007.github.io/three-things-daily/)
[![License](https://img.shields.io/badge/license-MIT-green?style=flat)](#)

---

## ✨ 特性

- 🎯 **聚焦三件事** — 每天只专注三件核心任务，拒绝过载
- 🌙 **深色主题** — 精心调校的暗色配色，渐变微光、流动线条、粒子动画
- 💾 **纯本地存储** — 数据保存在浏览器 LocalStorage，无后端、无隐私顾虑
- 📝 **任务管理** — 添加 / 完成 / 编辑 / 删除，点击文字即可行内编辑
- ✅ **完成反馈** — 勾选完成有波纹扩散 + 光点漂浮 + 脉冲光效，三件全部完成有彩虹祝贺动画
- 📝 **心得复盘** — 每个任务可撰写心得笔记，自动保存
- 🖼️ **图片模块** — 上传本地图片（自动压缩），拖拽排序，点击放大预览
- 📤 **导出 TXT** — 一键导出格式化的每日记录（含创建时间、完成时间、心得）
- 📱 **响应式** — 手机端 + 桌面端都好用
- 📦 **零依赖** — 单文件 HTML，仅通过 CDN 引入 Tailwind CSS

## 🚀 快速开始

### 在线使用

直接访问 GitHub Pages：

```
https://guiii007.github.io/three-things-daily/
```

### 本地使用

下载 `index.html`，用浏览器直接打开即可。

```bash
git clone https://github.com/guiii007/three-things-daily.git
cd three-things-daily
# 用浏览器打开 index.html
```

## 🎮 使用指南

| 操作 | 方式 |
|------|------|
| 添加任务 | 输入框键入内容，回车或点「添加」 |
| 完成任务 | 点击任务右侧对勾按钮 |
| 编辑任务 | 点击任务文字即可行内编辑，回车确认 |
| 删除任务 | 鼠标悬停任务卡片，点右上角 ✕ |
| 写心得 | 每个任务下方有文本框，自动保存 |
| 上传图片 | 点击右上角 ⬆ 图标，选择本地图片 |
| 图片排序 | 拖拽图片调整顺序 |
| 预览图片 | 点击图片放大查看，ESC 或点背景关闭 |
| 导出记录 | 点底部「导出 TXT」按钮 |

## 🛠️ 技术栈

- **HTML5** — 单文件应用
- **Tailwind CSS** — CDN 引入的原子化 CSS 框架
- **原生 JavaScript** — 无框架，无构建工具
- **LocalStorage** — 数据持久化
- **CSS Animations** — 波纹、光点、彩虹、脉冲等动效
