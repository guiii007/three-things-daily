# 给制作伙伴的 AI agent

你的工作是制作可被“三件事·像素伙伴”导入的 JSON 数据文件。先读 SPEC.md，参考 example.companion.json。与用户确认希望的角色外观；不要访问用户的任务数据，不要修改应用源码、注册表或启动项。

- 使用一个全新的唯一 id，禁止覆盖 capsule、chick 或已有作品。
- 使用 16～128 像素的透明画布，推荐 96×96，以保留角色细节和比例。像素风轮廓应完整、眼睛清楚、透明边距适当；预览时检查小尺寸的识别度。
- 使用 Node.js CLI 创建模板、校验与生成预览。不需要 npm install、远端 API 或专用 agent 插件。
- 从模板改造角色时，应真正修改像素行和颜色，而不是只更换名称。
- 不引入 JS、HTML、SVG、外部资源路径或 URL 作为伙伴数据。
- 完成后先运行 validate，再运行 preview 并打开预览检查外观。修复校验问题，不要把无效文件交给用户。
- 交付一个 .companion.json 文件，并说明“伙伴广场 → 导入伙伴 → 使用这个伙伴”的步骤。
- 如果用户提出动画需求，明确当前 v1 是单帧数据，应用会提供通用动画，不要虚构未支持字段。
