# 三件事 · 像素伙伴（Windows 试用版 0.4.1）

**简体中文** | [English](README.en.md)

## 使用

先通过托盘或管理窗口退出旧版，再[下载 Windows 0.4.1](https://github.com/guiii007/three-things-daily/releases/download/v0.4.1/ThreeThings-0.4.1-Windows.exe) 并双击运行，无需安装 Node.js。本机也可直接使用桌面“三件事·像素伙伴”快捷方式。已有任务、心得与大小设置会继续读取。

1. 写下一件事，点击“添加事情”。当天最多三件事，共用一个桌面伙伴。
2. 关闭管理窗口，胶囊仍会在其他软件上方显示。
3. 单击伙伴打开任务框，用“这件事 / 这桩事 / 这档事”按钮切换；只显示已经创建的事情。各自的内容与心得独立保存，切换前保存最后输入的文字。
4. 轻点胶囊立即打开任务框。按住胶囊约半秒，出现捏起动画后，保持按住鼠标移动；松手后落下并保存位置。长按不弹任务框，无需双击。
5. 点击“这件事完成啦 √”：自动保存当前这件事的 TXT，暖心笑脸和彩色鼓励文字出现后缓慢淡去；还有事情在进行时伙伴留下，全部完成或暂存后才退场。
6. 双击右下角系统托盘里的胶囊图标重新打开管理窗口；右键可隐藏伙伴或退出。

每天最多创建三件，完成后不释放当天名额。新的一天重新计算；过去的记录仍在历史列表中，未完成任务保留在历史中，但不会在次日自动显示伙伴。每天手动创建今天的任务，“明天继续”只记录进度，不会自动创建次日伙伴。

TXT 直接保存在 Windows 桌面，不再创建日期子文件夹。软件内“打开 TXT 文件夹”可直接打开桌面；“补存 TXT”可将已完成任务的文字记录保存到桌面。旧版已生成的文件保留在原位置。重新开启并再次完成任务会新增文件，保留上一次记录。

任务、心得和位置保存在 `%APPDATA%/three-things-companion/tasks.json`，不上传服务器。TXT 是完成时的纯文字快照；备份时建议同时备份此数据文件和完成记录文件夹。

当前桌面版与网页 `index.html`、浏览器试用版的数据分别保存；不会自动读取旧浏览器记录。原网页可继续独立使用。桌面版是首个 Windows 试用版本，提供本地伙伴广场及自定义伙伴导入，暂未提供自动更新。

## 开发

```powershell
npm.cmd install
node node_modules/electron/install.js
npm.cmd run prepare:assets
npm.cmd start
npm.cmd test
npm.cmd run build
```

`desktop/test/smoke.js` 使用 Playwright 启动真实 Electron，在 `.desktop-test` 目录隔离测试数据。开发者安装 Playwright 后可运行 `npm.cmd run test:desktop`；Codex 环境自动使用现有 Playwright。

Windows 透明窗口用原生 `setShape` 按像素裁出角色身体与小手，透明部分穿透鼠标。原生文件写入仅在主进程进行；渲染页面禁用 Node.js，使用沙箱与上下文隔离。

0.1.2 改为轻点 / 长按交互：轻点松手立即弹框；按住 500ms 捏起并拖动；松手落下。主进程直接读取 Windows 的当前鼠标位置和左键按下状态，不依赖透明窗口收到移动或松手事件。仅在角色被按住期间采样，不安装全局鼠标钩子、不记录输入。

`npm.cmd test` 覆盖长按时间边界、移出窗口、松手最终位置和短按误触；`npm.cmd run test:interaction` 检查轻点不再等待双击。手动原生输入测试可设置 `CAPSULE_TEST_ROOT` 为独立测试目录，并设置 `CAPSULE_NATIVE_UI_TEST=1`，角色窗口会扩大且有边框以供 Windows 测试工具选择；该模式不使用正式任务数据。

离线字体为 Fusion Pixel 12px Proportional SC（SIL Open Font License），授权文件随软件打包。Electron 及 Chromium 的授权文件随运行环境一同分发。

0.1.3 简化管理窗口与纯文字记录输出，兼容旧版任务和文字记录。

0.1.4 完成任务和补存 TXT 均直接写入 Windows 桌面，旧文件保持原位置。

0.1.5 在管理窗口提供“伙伴大小”滑块（20%～200%）及恢复 100%，统一调整桌面伙伴，实时生效并自动保存。角色使用 SVG 像素方块绘制，窗口和鼠标有效区域同步缩放；列表缩略图和任务编辑框保持原尺寸。

0.1.6 将伙伴大小百分比改为数字输入框，输入 20～200 的整数立即调整，与滑块双向同步。空白、超出范围、小数不会提交，离开输入框时恢复上次有效值。

0.1.7 自动记住任务窗口最后的宽高，以及任务和心得文本框单独调整的高度。关闭重开、重启及新打开的其他任务框沿用最后设置；屏幕较小时窗口会适配可用区域。关闭时先保存文字与文本框尺寸，再完成关闭，避免立即关闭丢失调整。

## 伙伴广场

管理窗口点击“伙伴广场”，可以预览并选择像素胶囊、原画小鸡及已导入的伙伴。选择会应用于今天未完成的任务和之后创建的伙伴，不会增加任务名额。伙伴大小和拖动交互保持可用。

想让自己的 AI 制作伙伴：点击“导出 AI 创作包”，把导出的整个文件夹交给 agent，按其中的 AGENTS.md、SPEC.md 和模板生成伙伴 JSON，并运行校验和预览。之后点击“导入伙伴”，选择 .companion.json 文件，再点“使用这个伙伴”。无需软件源码、API 密钥或在线市场账号。

自定义伙伴存放在 `%APPDATA%/three-things-companion/companions`。这是本地伙伴库，可以分享 JSON 文件；当前支持单帧像素形象，软件提供通用动画。开发测试可运行 `npm.cmd run test:library`。

管理窗口和托盘菜单显示版本号。升级时须先点击“退出软件”，仅关闭窗口不会退出旧进程。伙伴广场包含胶囊与青绿色小鸡，小鸡保持原本青绿色并去掉腹部环带，胶囊固定为暖黄色。托盘右键菜单支持可选开机自启动。

0.4.0 改为当天所有事情共用一个桌面伙伴和一个任务窗口。“这件事 / 这桩事 / 这档事”按钮按创建数量出现，保存当前内容后切换，各自完成状态与 TXT 独立。旧任务位置迁移为共享伙伴位置，并保留大小与输入框尺寸。

0.4.1 内置小鸡改用与桌面图标相同的高清透明原画，按原图平滑缩放，不再用像素网格重画。保留青绿色和原本的眼睛、腮红及身体比例，无环带；胶囊和导入的像素伙伴保持原有画法。
